SSI Next.js Blog Starter (Ready for Vercel)

Quick non-dev steps to use this repo:
1. Unzip the starter and upload its contents to a new GitHub repository (via the GitHub web UI: Add file → Upload files).
2. In Vercel: New Project → Import Git repository → choose this repo → Deploy (Vercel will detect Next.js).
3. To add posts: open the `posts` folder in GitHub, click Add file → Create new file → name it `yyyy-mm-dd-your-title.md` and paste content (example below). Commit, and Vercel will auto-deploy.

Example post frontmatter (copy/paste into a new file in `/posts`):
---
title: My first post
date: 2025-09-27
description: Short excerpt for SEO.
---

Write your post in Markdown below the frontmatter.
